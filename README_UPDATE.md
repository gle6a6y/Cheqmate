# Обновление функционала рулетки и тестового входа

## Исправленные проблемы:

### 1. Тестовый вход
**Проблема:** После нажатия кнопки "Тестовый вход" появлялась только кнопка "Выйти из аккаунта".

**Решение:**
- Обновлен `MainActivity.java` - добавлены кнопки "Создать чек" и "Мои группы"
- Обновлен `activity_main.xml` - улучшена разметка с кнопками для навигации
- Теперь пользователь может полноценно тестировать приложение после тестового входа

### 2. Функционал рулетки
**Проблема:** Рулетка запрашивала данные чека, хотя должна просто выбирать плательщика.

**Решение:**
- Упрощен `FortuneWheelActivity.java` - убраны поля ввода данных чека
- Обновлена разметка `activity_fortune_wheel.xml` - удалена форма ввода данных
- Рулетка теперь просто крутится и возвращает случайного плательщика
- Результат рулетки автоматически применяется при создании чека

### 3. Интеграция рулетки с созданием чека
**Решение:**
- В `CreateChequeActivity.java` добавлена кнопка "Использовать рулетку"
- Реализован обмен данными между активностями через `startActivityForResult`
- Выбранный плательщик автоматически применяется ко всем позициям чека

## Новый функционал:

### 1. Кнопка рулетки в создании чека
- На экране создания чека добавлена кнопка "Использовать рулетку"
- При нажатии открывается экран рулетки
- После выбора плательщика результат возвращается в создание чека

### 2. API рулетки на бэкенде
- Создан `FortuneWheelController.java` с эндпоинтом `/api/fortune-wheel/spin`
- Добавлены DTO: `FortuneWheelRequest.java`, `FortuneWheelResponse.java`
- Простая реализация случайного выбора плательщика

### 3. Обновленный интерфейс
- Главный экран теперь содержит навигационные кнопки
- Улучшено визуальное оформление
- Добавлена обратная связь через Toast сообщения

## Архитектура:

### Frontend (Android):
1. **StartActivity** - экран входа с тестовым доступом
2. **MainActivity** - главный экран с навигацией
3. **CreateChequeActivity** - создание чека с интеграцией рулетки
4. **FortuneWheelActivity** - рулетка для выбора плательщика

### Backend (Spring Boot):
1. **FortuneWheelController** - контроллер для работы с рулеткой
2. **DTO классы** - для передачи данных между клиентом и сервером

## Использование:

1. **Тестовый вход:** Нажать "Тестовый вход" на стартовом экране
2. **Главный экран:** Появятся кнопки "Создать чек", "Мои группы", "Выйти из аккаунта"
3. **Создание чека:** Нажать "Создать чек"
4. **Использование рулетки:** Нажать "Использовать рулетку" в форме создания чека
5. **Результат:** Выбранный плательщик автоматически применяется ко всем позициям чека
